# Security

Built for sensitive investment information. Security applies across every layer.

## Security controls

- **Encryption** — data encrypted in transit (TLS) and at rest. Encryption keys managed independently of the data they protect.
- **Authentication** — modern, phishing-resistant authentication with support for security keys and single sign-on where the firm requires it.
- **Authorization** — fine-grained, role-based access control so every member sees only what their role and firm configuration allows.
- **Tenant isolation** — each firm operates in an isolated tenant. Data, documents, and access are scoped to the firm, never shared across tenants.
- **Document permissions** — document-level permissions mirror the sensitivity of the material. Access is granted by role, deal, and workstream.
- **Audit trails** — sensitive actions — views, exports, permission changes, and deletions — are recorded so the firm can reconstruct what happened and when.
- **Access logs** — firms can review who accessed what, from where, and when.
- **Data retention** — retention and deletion policies are configurable per firm, and deletion is designed to be complete when the firm requires it.
- **Backups** — data is backed up with redundancy and tested restoration.
- **AI data handling** — AI processing is scoped to the firm's own data, respects document permissions, and is never used to train models shared across customers.
- **Infrastructure security** — hardened, managed infrastructure with environment separation between development, staging, and production.
