# Portfolio / Value Creation

The investment thesis should not disappear after closing. The platform keeps the underwritten case visible against actual performance, so monitoring, value creation, and exit are one continuous thread — not a fresh start.

The underwritten case is the baseline. Actual performance is measured against it, for the life of the investment.

## Pipeline

Underwrite → Acquire → Operate → Monitor → Exit

## Capabilities

- **Underwritten vs actual** — revenue, EBITDA, margin, cash flow, working capital, and leverage tracked against the original case.
- **KPIs** — the metrics your firm cares about, monitored on the cadence you set.
- **Operating initiatives** — value creation initiatives tracked with owners and progress.
- **Budgets & forecasts** — budgets and forecasts sit alongside actuals so variance is always visible.
- **Covenants** — covenant headroom and compliance tracked before they become a surprise.
- **Alerts** — significant changes and threshold breaches surfaced for review.
- **Continuity** — the thesis, diligence, and transaction record remain attached to the investment.
- **Exit readiness** — the full investment history is ready to support an exit when the firm decides the time is right.

## The principle

The investment thesis should not disappear after closing. It is the baseline for every monitoring decision and the foundation of the next one.
